# RepSnack Website (`repsnack.com`)

This directory is the dedicated project workspace for the marketing, documentation, and compliance website for **RepSnack** (`repsnack.com`).
- **Official App Store URL:** [RepSnack on the App Store](https://apps.apple.com/us/app/repsnack/id6797024053) (ID: 6797024053)

## Included Context & Assets:
- `Website_Plan.md`: Full architectural blueprint, free Cloudflare Pages hosting plan, Resend SMTP Gmail integration, AEO/SEO schema markup, and App Store compliance requirements.
- `repsnack_design_context.md` (or `snackt_design_context.md`): Authoritative product context, science citations (Gao et al. 2024), feature tiers, and copy guidelines.
- `stitch_snackt_hourly_movement_coach/`: Raw design exports from Google Stitch containing `liquid_vitality/DESIGN.md` (color tokens, font metrics) and high-resolution screen PNGs and HTML references.
- `exercise_assets/`: Exported 1024x1024 transparent/teal PNGs and animated GIFs of the four exercises (`AirSquat`, `CalfRaise`, `InclinePushUp`, `StandingMarch`), plus production app icon variants. **Do not use static raw SVGs — use these high-resolution PNGs and animated GIFs for the website.**
- `app_icons/`: Production 1024x1024 app icons (Light, Dark, Tinted).
